# WSL Setup (Ansible) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an idempotent Ansible playbook that sets up a complete WSL development environment with k8s tools, Python (pyenv), Go (goenv), starship terminal prompt, and VS Code WSL integration.

**Architecture:** A bash bootstrap script installs Ansible if absent, then delegates to `site.yml`, which runs six roles (base, python, go, k8s, terminal, vscode) tagged for selective re-execution. Idempotency is guaranteed at every layer: apt modules by nature, version managers via `--skip-existing`, GitHub binaries via `stat` checks, and `~/.bashrc` entries via `lineinfile` with regexps.

**Tech Stack:** ansible-core (apt), Bash, Ubuntu 26.04, pyenv, go-nv/goenv, starship, kubectl/helm/k9s/kubectx/kubens/kustomize/flux/argocd

### Task 3: python role (pyenv)

**Files:**
- Create: `roles/python/tasks/main.yml`

- [ ] **Step 1: Create directory**

Run: `mkdir -p roles/python/tasks`

- [ ] **Step 2: Create roles/python/tasks/main.yml**

```yaml
---
- name: Install pyenv build dependencies
  become: true
  ansible.builtin.apt:
    name:
      - libssl-dev
      - zlib1g-dev
      - libbz2-dev
      - libreadline-dev
      - libsqlite3-dev
      - libncursesw5-dev
      - xz-utils
      - tk-dev
      - libxml2-dev
      - libxmlsec1-dev
      - libffi-dev
      - liblzma-dev
    state: present

- name: Check if pyenv is installed
  ansible.builtin.stat:
    path: "{{ ansible_env.HOME }}/.pyenv/bin/pyenv"
  register: pyenv_binary

- name: Clone pyenv
  ansible.builtin.git:
    repo: https://github.com/pyenv/pyenv.git
    dest: "{{ ansible_env.HOME }}/.pyenv"
    version: master
    update: false
  when: not pyenv_binary.stat.exists

- name: Set PYENV_ROOT in .bashrc
  ansible.builtin.lineinfile:
    path: "{{ ansible_env.HOME }}/.bashrc"
    regexp: '^export PYENV_ROOT='
    line: 'export PYENV_ROOT="$HOME/.pyenv"'

- name: Add pyenv bin to PATH in .bashrc
  ansible.builtin.lineinfile:
    path: "{{ ansible_env.HOME }}/.bashrc"
    regexp: '^export PATH="\$PYENV_ROOT'
    line: 'export PATH="$PYENV_ROOT/bin:$PATH"'

- name: Initialize pyenv in .bashrc
  ansible.builtin.lineinfile:
    path: "{{ ansible_env.HOME }}/.bashrc"
    regexp: '^eval "\$\(pyenv init'
    line: 'eval "$(pyenv init -)"'

- name: Get latest stable Python version
  ansible.builtin.shell: |
    export PYENV_ROOT="{{ ansible_env.HOME }}/.pyenv"
    export PATH="$PYENV_ROOT/bin:$PATH"
    pyenv install --list | grep -E '^\s+[0-9]+\.[0-9]+\.[0-9]+$' | tail -1 | tr -d ' '
  register: latest_python
  changed_when: false

- name: Install latest stable Python
  ansible.builtin.shell: |
    export PYENV_ROOT="{{ ansible_env.HOME }}/.pyenv"
    export PATH="$PYENV_ROOT/bin:$PATH"
    pyenv install --skip-existing {{ latest_python.stdout }}
  args:
    creates: "{{ ansible_env.HOME }}/.pyenv/versions/{{ latest_python.stdout }}"

- name: Set global Python version
  ansible.builtin.shell: |
    export PYENV_ROOT="{{ ansible_env.HOME }}/.pyenv"
    export PATH="$PYENV_ROOT/bin:$PATH"
    pyenv global {{ latest_python.stdout }}
  changed_when: false
```

- name: Configure WSL interop to inherit Windows PATH
  become: true
  ansible.builtin.blockinfile:
    path: /etc/wsl.conf
    create: true
    marker: "# {mark} ANSIBLE MANAGED - interop"
    block: |
      [interop]
      appendWindowsPath = true
    mode: '0644'

- name: Check if code command is available in PATH
  ansible.builtin.shell: command -v code
  register: code_in_path
  failed_when: false
  changed_when: false

- name: Find VS Code installation in Windows paths
  ansible.builtin.shell: |
    for path in \
      "/mnt/c/Users/{{ ansible_env.USER }}/AppData/Local/Programs/Microsoft VS Code/bin" \
      "/mnt/c/Program Files/Microsoft VS Code/bin"; do
      if [ -d "$path" ]; then
        echo "$path"
        exit 0
      fi
    done
    exit 1
  register: vscode_found_path
  failed_when: false
  changed_when: false
  when: code_in_path.rc != 0

- name: Add VS Code to PATH in .bashrc
  ansible.builtin.lineinfile:
